# Contributing

Bug reports, ideas and pull requests are welcome.

When reporting a problem, please include your platform, the app version (shown under License), your car's hardware (HW3 or HW4) and firmware version if you know them, and what you expected to see. A short clip that shows the problem helps a lot, but think twice before sharing one publicly, since dashcam clips contain the location of the drive.

Desktop code is in `tesla_overlay.py` (app and window), `tesla_overlay_core.py` (telemetry, overlay, driving path, video) and `tesla_map.py` (maps), with the interface in `ui.html`.
